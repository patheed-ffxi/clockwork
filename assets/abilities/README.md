# Ability icons

`provoke.png` is the automaton's Provoke. Provoke lands no effect and is a mobskill,
so the game has no icon for it; this one was generated with ChatGPT for clockwork.

clockwork loads it through D3DX the first time it is drawn. When the file is missing
it falls back to the icon of the attachment that grants Provoke — so deleting it costs
you the look, not a feature.

This image is not Final Fantasy XI artwork. It is covered by clockwork's MIT license
along with the code.
